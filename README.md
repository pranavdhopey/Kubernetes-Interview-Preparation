## How to Use This Repository

Read the articles in order to build from Kubernetes architecture and networking fundamentals toward service discovery and production deployment practices. For interview revision, review the **Interview-ready answer** and **Key Takeaways** sections in each article.

## Article Format

Each article uses a consistent pattern:

1. Article title and question number.
2. Reframed interview question and clear explanation.
3. Practical example or configuration, when relevant.
4. Concise interview-ready answer.
5. Five bullet-point key takeaways.

The depth of examples varies by topic: architecture requires a component walkthrough, while Service types and labels benefit from YAML examples.
